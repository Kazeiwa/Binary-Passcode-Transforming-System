# V2.1.0

- RGB由同一比特的三份副本改为三个独立信道；每个选中通道奇数为1、偶数为0。定位标记只使用R通道，G/B可承载数据。
- 正文300,000比特，60,000个五位单元；全扩展BMP文本最多10,000字符。保留精确末尾空格。
- 随机编号由128比特扩为384比特；正文掩码1,172个HMAC块，像素位置派生同步更新。共享密钥和密钥库格式不变。
- 时间使用UTC 1970-01-01 00:00:00起的10位秒级Unix数值，加密后以5字节二进制封装。解密仅显示精确到秒的北京时间，不显示时间戳，不使用毫秒。
- PNG/JPG/BMP/WebP/TIFF等静态载体统一转换为RGB PNG输出。低于最低总像素或不能容纳完整块布局时报错；方图最低参考为均衡560×560、增强696×696，推荐1024×1024及以上。
- 约100万像素以内留白4%，每翻倍增加约2个百分点，最大12%；最大输入80MP、单边20,000，分条定位减少内存峰值。
- 自动兼容读取V2.0图片；旧图时间仅精确到分钟并明确标注，新图只使用2.1格式。
- 保留多密钥管理、加密备份、系统保护和完整消息认证，界面风格不变。
