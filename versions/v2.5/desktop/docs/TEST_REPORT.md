## 实际边界

秘密图片不设预定分辨率上限，但仍受150MiB文件大小、格式解码能力和设备内存限制。JPEG可降采样读取，PNG等可能需要完整原始像素的解码内存。

质量及最终尺寸取决于载体预算，不能承诺所有图片同时保持1080P和固定画质。高噪声测试图会触发明显缩小；界面显示实际结果。

纠错不保证任意裁剪；外层PNG被缩放、截图或有损转换可能损坏消息。本次未进行Linux实机或安卓适配。新图片消息需要V2.5接收端，原文字协议互通保留。既有详细矩阵见[文字传输基线](TEST_REPORT_V2.1.md)。
