# 第三方组件

以下许可证随软件附带；实际依赖以requirements.txt和本机安装结果为准。Windows EXE同时包含Python、Tcl/Tk及其运行库。

- Pillow 13.0.0: licenses/Pillow/LICENSE
- numpy 2.5.4: licenses/numpy/COPYING, licenses/numpy/LICENSE, licenses/numpy/LICENSE.md, licenses/numpy/LICENSE.txt, licenses/numpy/dragon4_LICENSE.txt
- cryptography 50.0.2: licenses/cryptography/LICENSE, licenses/cryptography/LICENSE.APACHE, licenses/cryptography/LICENSE.BSD
- reedsolo 1.7.0: licenses/reedsolo/LICENSE
- cffi 2.1.1: licenses/cffi/LICENSE
- pycparser 3.12: licenses/pycparser/LICENSE
- pyinstaller 6.22.3: licenses/pyinstaller/COPYING.txt

依赖的上游版权归各自作者。PyInstaller用于Windows打包，bootloader分发例外以其附带许可证为准。

Python许可证见licenses/Python-LICENSE.txt；Tcl/Tk核心许可证见licenses/TCL-license.terms与licenses/TK-license.terms。licenses各子目录另保留依赖安装包中的完整、带原路径文件名的许可证文本，避免同名文件覆盖。
