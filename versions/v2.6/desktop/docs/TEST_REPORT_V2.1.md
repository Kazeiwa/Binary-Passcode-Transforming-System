启用BIP_RUN_LARGE=1的完整测试：57项通过；默认测试55项通过、2项高清测试跳过。包括BMP全部63,488个标量值、300,000比特容量、60000单元边界、尾部空格、秒级Unix时间范围、错误密钥、认证字段修改、任意k块恢复、横竖及细长图片、裁剪、旋转、纠错、取消、命令行CRLF保留和文件覆盖保护。

密钥库测试覆盖CRUD、重启解锁、加密备份、错密码、损坏备份、并发修改、写入失败和Windows原生DPAPI；Linux系统密钥环调用及库流程通过模拟测试。

真实Tk界面测试覆盖图片选择、加密保存、裁剪解密、剪贴板、新增/重命名/设默认/删除密钥、加密备份导出导入、锁定解锁和920×680紧凑布局；截图来自程序自身窗口。

## 性能与限制

本机1024×1024数组嵌入约0.300秒，原图数组提取约0.386秒；不包括PNG读写及界面操作。性能随机器和图片内容变化。

容量和可读块门限是协议条件；这些裁剪例子不是“任意裁去同等面积都能恢复”的承诺。裁剪切断定位点会使整个块不可用，增强模式通过更多冗余改善恢复率。

V2.1不再使用三通道多数表决，整张图红通道奇偶翻转按预期失败。少量通道错误仍可通过块内RS纠错修复，但不属于三通道备份。JPEG、缩放按预期失败说明该版不应宣称抗有损压缩。

Windows打包版另有冻结程序启动及加解密验证。真实Linux桌面/Secret Service尚未实测；不把模拟测试当作Linux实机验证。该协议没有独立密码学认证或不可检测性证明。
