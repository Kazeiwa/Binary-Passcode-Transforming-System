## 能力边界

PNG无损指1080P适配后的8位RGB/RGBA像素；大图适配本身仍改变原图，不保留原始文件元数据或字节。PNG无损新传输不支持裁剪或正文纠错，需要完整像素数据；直角旋转和像素不变的重新压缩可以恢复。

容量随PNG实际大小变化，复杂图需要更大底图；源码资源上界不代表所有设备具有足够内存。本次发布面向Windows，未同步安卓新功能或进行Linux实机测试。
