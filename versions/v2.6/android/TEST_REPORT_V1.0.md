# Android 首发版测试记录

日期：2026-11-03。版本：1.0。构建环境：Windows、JDK 17、Android SDK 36、Build Tools 36.0.0。

## 核心与互通

- SHAKE256已知向量及与Python位置排列互通。
- 穷举63,488个BMP非代理码点，分批编码、解码完全一致。
- 60,000单元满容量正文、时间范围终点、消息认证及篡改拒绝。
- 内层RS分块纠错：每块16个字节错误仍能恢复；外层任意有效k块恢复。
- 19项图片互通测试通过：Java与Python双向读写，均衡560×560、增强696×696、两模式1024×1024，裁剪，90°/180°/270°旋转，每块头部及正文12字节纠错，错误密钥拒绝，过度裁剪拒绝，封装互通，实际APK使用的PNG写入器与电脑端互通。
- 1,200万像素图片，四边各裁去8%后，Java核心仍能恢复消息。此项在桌面JVM执行，不代表所有手机都能处理相同尺寸。
- APK实际使用的流式PNG写入器经独立读取，所有RGB字节保持一致。

## 安卓界面与密钥流程

Robolectric 4.16.1共6项测试通过：

1. 三页启动、导航、容量计数与发布提示。
2. 密钥生成/导入所用存储流程、重命名、默认密钥、删除、重新读取，加密备份合并、重复恢复与篡改备份拒绝。
3. 空输入校验、对话框和异步取消，取消后界面恢复可用。
4. 经系统文档提供者读取PNG尺寸。
5. Android 15原生绘图后端绘制三页界面，生成截图并人工检查；原生Bitmap读取验证RGB值。
6. AtomicFile备份恢复、损坏密钥库保留、新建密钥库入口与恢复加密备份。

流程测试使用Android 9框架；原生绘图测试使用Android 15框架。测试密钥仅在测试中临时生成。AndroidKeyStore在这些测试中由专门的内存测试提供者替代，生产APK使用真实系统密钥库。

## 发布检查

- release模式、`debuggable=false`，最低API 26，目标API 36。
- APK签名v2/v3验证和ZIP对齐检查通过。
- APK不包含测试类、测试密钥、签名私钥、Python运行环境或原生ABI库；不请求联网权限或全盘存储权限。
- 发布包有独立SHA-256校验文件。用户说明没有旧版本历史或开发过程提示。

未进行安卓真机安装、硬件密钥库或不同厂商文件选择器的实测。API 36已编译与签名验证，未在该系统上运行界面测试。截图为本应用在安卓框架原生绘图后端生成的测试界面，不是真机截图。
