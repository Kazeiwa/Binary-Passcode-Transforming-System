# 二进制密码转换终端 · 图片版

安卓首发版 1.0，适用于 Android 8.0 及以上系统。

## 开始使用

1. 安装 `binary_image_passcode.apk`。
2. 进入“密钥”，生成或导入128位数字密钥。点击密钥名称，可以设为默认、重命名、复制或删除。
3. 加密时，选择图片和密钥，输入正文，点击“加密并保存 PNG”，选择保存位置。
4. 将生成的 PNG 以**文件或原图**发送。接收者导入同一把密钥，在“解密”中选择图片并解密。

图片与消息在本机处理，无需联网或安装 Python。可与电脑端交换图片消息和128位通信密钥。

## 图片要求

支持系统可读取的静态 PNG、JPG、BMP、WebP 等图片，统一保存为 PNG。

| 恢复模式 | 最低总像素 | 方形图片参考 |
| --- | ---: | --- |
| 均衡 | 313,600 | 560×560 |
| 增强 | 484,416 | 696×696 |

推荐 **1024×1024及以上**。短边至少140像素，实际长宽比也须满足完整数据块的布局要求；不满足时会给出提示。大图会自动增加边缘留白，并将数据块分散放置。增强模式可以容忍更多完整数据块丢失，但需要更大的载体。

程序支持有限度裁剪、直角旋转及少量数据损坏的恢复；过度裁剪、缩放、截图或转换为 JPG，可能使消息无法读取。请保留加密图片原文件。图片上限为8,000万像素、单边20,000像素、文件150MB；手机实际可处理的尺寸也取决于可用内存，内存不足时会提示，不会自行缩放密文图片。

## 正文与时间

正文最多60,000个编码单元。小写英文字母通常各占1单元，数字及大小写切换还会使用控制单元。中文、日文、韩文及其他扩展字符通常每字占6单元。界面会自动计算用量，超出容量时不能加密。

支持大小写英文字母、数字、常用半角符号和大部分中日韩文字，暂不支持部分表情、罕见字等补充平面字符。原文中的换行和尾部空格会保留。

解密后显示**精确到秒的北京时间**。生成时间取自发送设备的时钟。

## 密钥与备份

可保存多把密钥，为不同联系人分别命名。每次操作可选择密钥，新建消息默认使用默认密钥。密钥名称及密钥本身一起加密保存在应用私有目录，保护密钥由安卓系统密钥库管理。

请在“密钥”页导出加密备份，设置至少12个字符的备份密码。换手机或重装后，可在本应用中恢复备份；恢复会合并密钥，不会清空现有记录。备份密码不能找回，请与备份文件分开妥善保存。

卸载应用或清除应用数据会删除本地密钥。安卓备份文件用于本图片版安卓应用；与电脑端交换密钥时，请复制128位原始密钥，保留所有前导零。

## 常见问题

- **无法验证消息**：检查密钥是否一致，图片是否为原始 PNG，是否被修改。
- **可读数据块不足**：裁剪或损坏超过恢复能力，请重新获取完整图片。
- **图片太小或长宽比不适合**：换用更大、较接近方形的图片，或改用均衡模式。
- **无法读取本地密钥库**：先保留应用数据；可选择新建空密钥库，再用原始密钥或加密备份恢复。损坏记录会留在应用私有目录中。
