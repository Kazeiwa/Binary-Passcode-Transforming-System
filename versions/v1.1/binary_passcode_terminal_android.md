# 二进制密码转换终端 V1.1 — Android版

安装文件：`binary_passcode_terminal.apk`。支持Android 8.0及以上，内含arm64-v8a、armeabi-v7a、x86_64三种架构，不需要Python或额外运行库。

应用有“加密”“解密”“密钥”三个页面。首次使用先进入密钥页，导入双方约定的128位半角数字密钥，或生成新密钥后在另一端导入。开头的零不可省略。

正文支持BMP范围内全部Unicode标量值；已有基础字符使用短编码，其他字符每个占6个编码单元。最多100个字符、100个单元。补充平面字符（例如部分emoji、生僻字）仍不支持。安卓正文框支持多行，换行也占一个6单元扩展字符。

加密结果固定200位数字，可直接复制；解密会显示北京时间和正文。末尾填充空格保留。Android、Windows EXE和Python使用相同的C++/Python协议格式，可以互通。

## 密钥存储

手机上的原始128位通信密钥，由Android Keystore生成的设备本地AES-256密钥通过AES-GCM保护。应用私有存储中只保存密文和IV。应用没有联网权限，也不申请外部存储权限；不会把原始密钥写入明文文件。

显示和复制密钥都需要主动操作。密钥显示和导入窗口禁止普通截图；复制内容会标为敏感剪贴板数据，具体系统显示方式依手机版本而定。

卸载、清除数据和更换手机前，请备份原始128位通信密钥。加密存储记录与本机系统绑定，不能直接搬到其他设备。跨设备使用应在目标设备重新导入原始密钥。

## 安装和升级

使用手机的APK安装功能安装即可，系统可能要求允许当前文件管理器安装应用。应用包名为 `org.binarypasscode.terminal`，版本号1.1，版本代码11，未启用调试模式。

以后覆盖升级需要相同包名和相同APK签名证书。此次签名证书和密码文件保存在构建主机的 `work/android-signing` 目录，未放入发布包；这是应用发布签名，与通信密钥不同，请单独保管。

APK已通过v2/v3签名验证、ZIP完整性和16KB页对齐检查，三个架构的原生库均已编译。JNI桥接与Python通过100组主机JVM互通测试。当前未连接安卓手机或模拟器，因此未实测手机上的界面和Keystore读写；首次在手机使用时应先用普通测试文本确认两端互通。

## 构建源码

源文件是根目录的 `binary_passcode_terminal.cpp`，Java界面和Keystore代码位于 `android/src/org/binarypasscode/terminal`。构建入口为 `android/build_android.py`，依赖和签名说明见 `binary_passcode_terminal_cpp_build.md`。
