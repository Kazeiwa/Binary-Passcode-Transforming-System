# 二进制密码转换终端 V1.1 — 加密时间区

运行 `binary_passcode_terminal.py`。密文仍为200位半角数字，私钥仍为原来的128位数字，本地密钥存储方式不变。

前8位现在是加密后的分钟序号。原点固定为北京时间2000-01-01 00:00，精确到分钟，舍去秒和微秒；可表示的最后一分钟为2190-02-17 10:39。加密时间在此范围外会报错，不循环回绕。

时间偏移量由私钥和本条消息的128位随机编号，通过独立用途的HMAC-SHA256派生。加密时间为“分钟序号加偏移量，模一亿”。正文使用另一用途标记派生掩码，并绑定原始分钟序号及随机编号。解密严格按先恢复时间、再恢复正文的顺序执行，并显示北京时间。

接口 `encrypt(text, key, generation_date=None)` 保留旧参数名，省略时使用当前时间；测试时可传入datetime、`YYYYMMDDHHMM`，或代表当天零点的`YYYYMMDD`。无时区的datetime视为北京时间，有时区的datetime先换算至北京时间。`decrypt(cipher, key)` 仍只返回正文；新增 `decrypt_with_time(cipher, key)` 返回“带时区的datetime、正文”二元组。

该时间区格式不能与旧日期明文格式混用；由于没有增加版本字段，程序不自动判断旧密文。读取旧密文请运行保留的 `decimal_cipher_200_v2_legacy.py`。当前C++源码和EXE已同步该格式，与正式版Python互通。正式发布名称为“二进制密码转换终端 V1.1”；源码中的v3仅是内部加密用途标记。

已通过308组时间与正文往返测试、独立HMAC向量验证、范围边界、时区换算、闰日、分钟截断、全零加密时间区和非法输入测试；BMP扩展后的630组文字编码回归及本地DPAPI存储测试也通过。字符范围现已扩大至BMP全部标量值，基础短编码及加密时间区格式不变。
